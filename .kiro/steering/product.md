# Product Overview

語学学習アプリで、ユーザーが練習フレーズを声に出して録音した音声を受け取り、変換して保存し、あとから取り出せるようにするバックエンドサービス。クライアントはモバイル端末で、ユーザーは用意された練習フレーズの中から選んだものを練習する。

## Core Capabilities

- **音声の保存**: ユーザーとフレーズを指定して音声ファイルを受け取り、サーバーで決めた1つの保存用フォーマットに変換して、ディスクに保存する。保存したファイルのパスは、ユーザーとフレーズに紐づけてデータベースに記録する
- **音声の取得**: ユーザーとフレーズを指定し、保存済みの音声を、クライアントが求めるフォーマットに変換して返す
- **ID の検証**: どちらの操作でも、ユーザー ID とフレーズ ID がデータベースにある有効な ID かを確かめる

## Target Use Cases

- ユーザーがフレーズを練習して録音し、その音声をアップロードする
- ユーザーがあとから、練習したフレーズの録音を聞き返すために取り出す

## Value Proposition

- クライアントが送受信するフォーマットと、サーバーが保存するフォーマットを切り離す。クライアントは保存用のフォーマットを意識せずに済み、サーバーは保存したファイルを1つのフォーマットで扱える

## Scope

- 公開するエンドポイントは、保存の `POST /audio/user/{user_id}/phrase/{phrase_id}` と、取得の `GET /audio/user/{user_id}/phrase/{phrase_id}/{audio_format}` の2つ
- ユーザーとフレーズは ID だけを扱い、名前などの属性は持たない
- 音声フォーマットは、送受信用と保存用の2つだけを扱う。具体的な形式は技術選定で決める
- サービスとデータベースは、Dockerfile を使って手元のマシンで起動できるようにする
